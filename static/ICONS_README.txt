PWA Icons
=========

Für die PWA-Installation benötigst du Icons:

Option 1: Automatisch generieren (empfohlen)
---------------------------------------------
Nutze ein Online-Tool wie https://realfavicongenerator.net/
- Lade ein beliebiges Bild hoch
- Lade die generierten Icons herunter
- Benenne sie um zu: icon-192.png und icon-512.png

Option 2: Manuell erstellen
----------------------------
Erstelle zwei PNG-Dateien:
- icon-192.png (192x192 Pixel)
- icon-512.png (512x512 Pixel)

Lege sie in den static/ Ordner.

Hinweis: Die App funktioniert auch ohne Icons, aber für die Installation
auf dem Homescreen sind sie empfohlen.
